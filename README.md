# FitLog

A responsive workout library to explore exercises, build a daily plan, and save workouts for later.

## Technologies
- Next.js (App Router)
- React and TypeScript
- Tailwind CSS and DaisyUI

## Key Features
1. Browse workout cards and view exercise details.
2. Add workouts to today’s plan (maximum five).
3. Save workouts to try later.
4. Track total exercises, minutes, and estimated calories.
5. Mark planned workouts as done or remove them.
6. Sort workouts by duration, calories, or rating.
7. Keep the plan and saved workouts after refreshing the page.
